# Build Viby

**Build Viby** is a project-based, beginner-to-professional full-stack course that teaches modern web and product engineering by actually building something real. Instead of disconnected tutorials, you ship **Viby** — a premium, mobile-first social-discovery app — one section at a time. By the final chapter you won't just *understand* Next.js, TypeScript, Tailwind, and Supabase; you'll have engineered, designed, secured, and deployed a production-grade social platform with your own hands, and you'll think like the product builder behind it.

## Who this book is for

- Curious beginners who can write a little code and want a single, coherent path from "Hello World" to shipping a real app.
- Frontend developers ready to go full-stack and own the backend, database, and realtime layers.
- Bootcamp grads and self-taught engineers who want professional-grade patterns, not toy examples.
- Founders and product-minded builders who want to turn an idea into a deployed, scalable MVP.

## What you will be able to build

- A real, working social platform — profiles, discovery, connections, chat, and feeds.
- Complete full-stack applications, frontend to database, with clean architecture.
- Responsive, modern UIs that feel native on mobile and polished on desktop.
- Realtime systems — live chat, presence, notifications, and instant updates.
- Scalable production apps that are secure, observable, and ready for real users.

## The stack you will master

- **Next.js 16** — App Router and React 19 (Server Components, Server Actions, streaming).
- **TypeScript** — end-to-end type safety from the database to the UI.
- **Tailwind CSS v4** — CSS-first theming with `@theme` design tokens (no `tailwind.config.js`).
- **shadcn-style UI primitives** — composable, accessible, fully-owned components.
- **Framer Motion** — fluid micro-interactions and premium motion design.
- **Zustand** — lightweight client state for demo / in-memory mode.
- **Supabase** — Auth, PostgreSQL, Storage, and Realtime via `@supabase/ssr`.
- **Vercel** — zero-config, edge-ready production deployment.

**Brand identity:** bubblegum pink `#FF6FB5` on clean white, mobile-first, with a premium Gen-Z social aesthetic woven through every screen and component.

## How to use this book

This is a **project-based** book — you learn by building, not by reading alone.

- **Code along.** Type the code yourself; don't just skim it. Muscle memory matters.
- **Do the exercises and mini-projects.** Each chapter ends with hands-on work that locks the concept in.
- **Build Viby section by section.** Every chapter adds a real piece of the app, so progress compounds.
- **Choose your mode.** Run in **demo mode** (no keys, in-memory state with Zustand) to learn fast and offline, or **connected mode** (real Supabase Auth, database, storage, and realtime) to build the production app for real. The book guides both paths.

## How the chapters are structured

Every chapter follows the same rhythm so you always know where you are:

- **Theory** — the core concept explained clearly, from first principles.
- **In practice** — applying it to real Viby code.
- **Diagram** — a visual model of how the pieces fit together.
- **Best practices** — what professionals do, and the traps they avoid.
- **Exercises** — focused reps to make the concept stick.
- **Mini-project** — a self-contained build that proves you've got it.
- **Takeaways** — the essentials to carry into the next chapter.
